لوحة تحكم وثب

سجّل الدخول بمفتاح الدخول الخاص بحسابك على GitHub. يُسجَّل كل تعديل باسمك، ويُنشر على الموقع خلال دقيقة أو دقيقتين.

كيف أنشئ مفتاح الدخول؟
  1. ادخل إلى حسابك في GitHub، وتأكد من إضافتك كمشارك (Collaborator) في مستودع الموقع.
  2. افتح صفحة إنشاء مفتاح جديد. ستكون الصلاحية المطلوبة (public_repo) محددة تلقائياً.
  3. اختر مدة الصلاحية (مثلاً 90 يوماً)، ثم اضغط Generate token أسفل الصفحة.
  4. انسخ المفتاح والصقه هنا. لن يعرضه GitHub مرة أخرى، لذا احفظه في مكان آمن إذا احتجت إليه على جهاز آخر.
